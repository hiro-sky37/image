# KIRI — 画像背景透過ツール

HTML・CSS・JavaScriptのみで動作するローカル画像編集サイトです。外部サービスや画像の送信、依存パッケージはありません。公開していません。

## 開き方

`index.html` をブラウザで開きます。ローカルサーバーを使う場合は、このフォルダで以下を実行してください。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:4173 を開きます。

## 操作

- 画像を選択、またはドラッグ＆ドロップします。
- **自動で透過**：四隅の背景色を推定し、画像の端につながった近い色を削除します。許容範囲を広げると、より多くの色を削除します。
- **細部重視**：標準の背景判定後、消えた境界の画素を近隣の被写体色と背景色の混合として評価し、条件に合う画素だけを半透明で復元します。背景色が混ざった輪郭は近傍の被写体色に補正します。標準で残る画素は変更しません。従来どおりの結果には「標準」を選んでください。
- **拡大**：2倍・4倍・8倍で表示して細部を編集できます。表示倍率を変えても画像の画素数は変わりません。
- **離れた領域を除去**：標準で有効です。上下左右と斜めに連続する画素を調べ、最大の領域だけを残します。離れて配置された複数の被写体を残す場合はオフにしてください。
- **枠の外側を削除**：フリーハンドで残したい部分を囲みます。始点と終点を滑らかな曲線で結び、外側だけを消します。長方形への切り替えもできます。削除ボタンまたはEnterで適用します。
- **なぞって削除**：消したい範囲を囲みます。線は指を離すと滑らかな曲線で閉じます。削除ボタンまたはEnterで適用します。
- **消しゴム / 復元ブラシ**：マウスを押したまま、または指を置いたままドラッグして連続で編集します。丸いブラシ表示はドラッグ中も位置に追従します。ブラシサイズは画面上の大きさです。
- 白・黒・市松模様は確認用の背景です。透過PNGの保存には含まれません。保存名は `元の名前[背景無し].png` です。
- 元の画像と編集画像を切り替えられます。
- ⌘/Ctrl+Zで取り消し、⌘/Ctrl+Shift+Zでやり直し。A/R/L/E/Bでツールを変更。Escで選択を解除。

## 制限

自動透過は背景色による判定で、AIによる人物・物体認識ではありません。複雑な背景や被写体と背景が同色の画像は手動で調整してください。画像の端に被写体がある場合も自動判定が難しくなります。

30 MB以下の画像を開けます。大きい画像は長辺3200 px・約600万画素以内へ縮小され、編集後もそのサイズで保存されます。アニメーション画像は静止画として読み込みます。取り消し履歴はメモリ使用量に応じて古いものから整理されます。

## ファイル

- `index.html`：画面
- `style.css`：デザインとレスポンシブ対応
- `app.js`：画像読み込み・手動編集・履歴・PNG保存
- `selection.js`：フリーハンド選択の滑らかな閉曲線を生成。
- `processing.js`：背景色の判定、端からの背景除去、連結領域の整理。Web Worker内で実行。

処理の検証：

```sh
node tests/processing.test.js
node tests/detail.test.js
node tests/selection.test.js
```

細部重視の補正対象は、標準で残る不透明な被写体の近く（約3画素）の境界です。すでに画像自体から失われた髪の毛や、被写体と背景が同色で境界が判別できない部分を生成する機能ではありません。すべての写真で精度向上を保証するものではなく、元画像との比較と取り消しで結果を確認できます。

## 保存先の記憶

フッターの「保存先を変更」からフォルダを指定できます。WindowsのChrome・Edgeなど、File System Access APIに対応したブラウザで利用できます。ローカルHTTPサーバーまたはHTTPSで、同じアドレスから開いてください。選んだフォルダのハンドルはIndexedDBに記憶します。再起動後に書き込み許可を再確認する場合があります。ブラウザデータを消すと保存先の記憶も消えます。

未指定の場合と非対応ブラウザでは、従来のダウンロード保存を使います。同名ファイルが指定フォルダにある場合は「 (2)」などの番号を付け、既存画像は上書きしません。
