# KIRI — 画像背景透過ツール

HTML・CSS・JavaScriptのみで動作するローカル画像編集サイトです。外部サービスや画像の送信、依存パッケージはありません。公開していません。

## 開き方

`index.html` をブラウザで開きます。ローカルサーバーを使う場合は、このフォルダで以下を実行してください。

```sh
python3 -m http.server 4173 --bind 127.0.0.1
```

ブラウザで http://127.0.0.1:4173 を開きます。

## 操作

- 画像を選択、またはドラッグ＆ドロップします。
- **自動で透過**：四隅の背景色を推定し、画像の端につながった近い色を削除します。許容範囲を広げると、より多くの色を削除します。
- **離れた領域を除去**：標準で有効です。上下左右と斜めに連続する画素を調べ、最大の領域だけを残します。離れて配置された複数の被写体を残す場合はオフにしてください。
- **枠の外側を削除**：ドラッグして枠を作り、削除ボタンまたはEnterで適用します。
- **なぞって削除**：消したい範囲を囲みます。線は指を離すと閉じます。削除ボタンまたはEnterで適用します。
- **消しゴム / 復元ブラシ**：マウスや指で細部を編集します。ブラシサイズは画面上の大きさです。
- 白・黒・市松模様は確認用の背景です。透過PNGの保存には含まれません。
- 元の画像と編集画像を切り替えられます。
- ⌘/Ctrl+Zで取り消し、⌘/Ctrl+Shift+Zでやり直し。A/R/L/E/Bでツールを変更。Escで選択を解除。

## 制限

自動透過は背景色による判定で、AIによる人物・物体認識ではありません。複雑な背景や被写体と背景が同色の画像は手動で調整してください。画像の端に被写体がある場合も自動判定が難しくなります。

30 MB以下の画像を開けます。大きい画像は長辺3200 px・約600万画素以内へ縮小され、編集後もそのサイズで保存されます。アニメーション画像は静止画として読み込みます。取り消し履歴はメモリ使用量に応じて古いものから整理されます。

## ファイル

- `index.html`：画面
- `style.css`：デザインとレスポンシブ対応
- `app.js`：画像読み込み・手動編集・履歴・PNG保存
- `processing.js`：背景色の判定、端からの背景除去、連結領域の整理。Web Worker内で実行。

処理の検証：

```sh
node tests/processing.test.js
```
